# 甜品消消乐 Dessert Match-3 Game

这是一个用 Python + Pygame 开发的图形化甜品消消乐游戏。
游戏主题是“甜品”，棋盘里有小蛋糕、冰淇淋、橘子汽水、巧克力曲奇、面包、甜甜圈等不同图案。玩家通过点击两个相邻甜品进行交换，只要横向或纵向出现 3 个及以上相同甜品，就可以消除并获得分数。

## 项目简介

本项目是我的 Python 游戏开发练习作品，主要实现了消消乐类游戏的基础玩法，包括甜品图标交换、匹配检测、消除效果、音效反馈和背景音乐控制等功能。本项目还通过上传可爱的像素风甜品图案优化了游戏界面，增加了可爱的动画与交互效果，大大提高游戏体验。
游戏的基础规则是：
3 连：普通消除，获得基础分数。
4 连：生成半透明特殊甜品。半透明甜品与其他甜品交换后，会清除周围 3×3 区域。
5 连：生成彩虹糖。彩虹糖与普通甜品交换后，会清除棋盘中所有同类型甜品。
游戏一共有 10 个关卡。每一关不只是简单提高分数要求，还加入了不同目标，比如收集指定甜品、使用半透明甜品、使用彩虹糖、达成连击等，让关卡更有变化。

## 游戏功能

游戏还包含这些功能：
开始界面
关卡选择界面
通关、失败、全部通关弹窗
背景音乐开关按钮
鼠标点击交换甜品
自动提示可移动位置
没有可移动步骤时自动洗牌
连击提示
交换动画、消除动画、下落动画
爆炸粒子特效
可调整窗口大小，棋盘会自动适配
整体来说，它是一个比较完整的休闲消除类小游戏，既有基础消消乐玩法，也加入了特殊甜品、关卡目标、动画和音效，适合用来学习 Python 游戏开发中的界面绘制、鼠标交互、动画效果、关卡设计和游戏逻辑。
